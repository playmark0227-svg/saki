# 🌸 桜舞う、きみとの七日間

> ドキドキな展開の **恋愛シミュレーションゲーム（ビジュアルノベル）**
> ―― 満開の桜の下で出会った三人の少女。文化祭までの七日間、きみは誰と心を通わせる？

ブラウザだけで遊べる、インストール不要・外部依存ゼロの恋愛ADVです。
キャラクターの立ち絵はすべて **SVGで動的に描画**、BGM・効果音は **Web Audio APIで手続き的に生成**しています（画像・音声ファイルを一切同梱していません）。

---

## ▶ 遊び方

そのままブラウザで開くだけです。

```
# どちらでもOK
1. index.html をダブルクリックして開く
2. もしくはローカルサーバで配信
   python3 -m http.server 8000   →  http://localhost:8000
```

- **セリフ送り**：画面クリック／`Space`／`Enter`／`→`
- **選択肢**：好感度が変化します（左上のハートで確認）
- **セーブ／ロード**：右上のボタン（ブラウザの localStorage に保存）
- **♪ BGM**：右上のボタンでON/OFF

## 💕 ストーリー

春。坂の上の **星河（せいか）学園** へ転校してきた主人公（あなた）は、
満開の桜の下で三人の少女と、一人の先輩に出会う。みんな笑顔や仮面の裏に、それぞれの秘密を抱えていた――。

**文化祭までの七日間**。あなたが選んだ言葉と、共に過ごす時間が、ふたりの距離を変えていく。
3日目までの行動で最も心を通わせた相手の **個別ルート** へ進み、文化祭の夜、運命の告白を迎えます。

### 攻略キャラクター

| キャラ | タイプ | 抱える秘密 |
|--------|--------|------------|
| **結城 咲（ゆうき さき）** | 幼なじみの太陽。元気いっぱいのムードメーカー | 主人公と交わした幼い日の「約束」。明るさの裏の、置いていかれる怖さ |
| **氷室 雪乃（ひむろ ゆきの）** | 孤高の才媛。生徒会長で完璧主義のツンデレ | 家に縛られた進路と、誰にも言えない「物語を書きたい」という夢 |
| **七瀬 ひなた（ななせ ひなた）** | やわらかな光。マイペースな美術部の不思議っ娘 | 病弱だった過去。完成させられない一枚の絵に込めた「終わりへの怖さ」 |
| **月城 シオン（つきしろ シオン）** | 孤高の旋律。学園のプリンスと噂される三年生（男性） | かつて天才ピアニストだった過去。姉との「最後の約束」を守れず、人前で弾けなくなった |

### エンディング

各キャラに **トゥルー / グッド / ノーマル** の3エンディング、
**合計12の結末**を用意しています。好感度と、最後の選択であなたの物語が決まります。

## 🛠 技術メモ

| 項目 | 内容 |
|------|------|
| 構成 | 素のHTML / CSS / JavaScript（ビルド不要・フレームワーク不使用） |
| 立ち絵 | `js/characters.js` がSVGで動的生成（4キャラ × 10表情・男女の制服を出し分け） |
| シナリオ | `js/story.js` のシーングラフ（155シーン）をデータ駆動で進行 |
| エンジン | `js/engine.js`（進行・好感度・分岐・セーブ・タイプライター演出・音） |
| 音 | Web Audio APIによる手続き的BGM＆効果音（ファイルなし） |
| 演出 | CSSによる桜エフェクト・背景グラデーション・各種アニメーション |
| 保存 | localStorage |

### ファイル構成

```
saki/
├── index.html          # エントリーポイント
├── css/
│   └── style.css       # 全スタイル・背景・アニメーション
├── js/
│   ├── characters.js   # キャラ定義 ＋ SVG立ち絵ジェネレータ
│   ├── story.js        # シナリオ（シーンデータ）
│   └── engine.js       # ゲーム進行エンジン
└── README.md
```

### シナリオの追加・編集

`js/story.js` の `STORY` オブジェクトにシーンを足すだけで拡張できます。

```js
sample: {
  bg: "classroom",                 // 背景キー（css の .bg-xxx）
  who: "saki",                     // 話者: "" 地の文 / "player" 主人公 / キャラID
  exp: "smile",                    // 表情
  text: ["セリフ1ページ目", "2ページ目"],
  eff: { saki: 2 },                // 入室時に好感度加算（任意）
  flag: { met_saki: true },        // フラグ（任意）
  choices: [                       // 選択肢（任意。無ければ next へ）
    { label: "選択肢A", eff: { saki: 2 }, next: "sceneA" },
    { label: "選択肢B", next: "sceneB" },
  ],
  next: "nextSceneId",             // choices が無いとき
}
```
