# 🌸 桜舞う、きみとの七日間

> ドキドキな展開の **恋愛シミュレーションゲーム（ビジュアルノベル）**
> ―― 満開の桜の下で出会った三人の少女。文化祭までの七日間、きみは誰と心を通わせる？

ブラウザだけで遊べる、インストール不要・外部依存ゼロの恋愛ADVです。
キャラクターの立ち絵はすべて **SVGで動的に描画**、BGM・効果音は **Web Audio APIで手続き的に生成**しています（画像・音声ファイルを一切同梱していません）。

---

## ▶ 遊び方

そのままブラウザで開くだけです。

```
# どちらでもOK
1. index.html をダブルクリックして開く
2. もしくはローカルサーバで配信
   python3 -m http.server 8000   →  http://localhost:8000
```

- **セリフ送り**：画面クリック／`Space`／`Enter`／`→`
- **選択肢**：好感度が変化します（左上のハートで確認）
- **セーブ／ロード**：右上のボタン（ブラウザの localStorage に保存）
- **♪ BGM**：右上のボタンでON/OFF

## 💕 ストーリー

春。坂の上の **星河（せいか）学園** へ転校してきた主人公・**さき**（あなた／一人称「わたし」・名前は変更可）は、
満開の桜の下で、三人の同級生の男子と、一人の“憧れの先輩”に出会う。みんな笑顔や仮面の裏に、それぞれの秘密を抱えていた――。

**文化祭までの七日間**。あなたが選んだ言葉と、共に過ごす時間が、ふたりの距離を変えていく。
3日目までの行動で最も心を通わせた相手の **個別ルート** へ進み、文化祭の夜、運命の告白を迎えます。

### 攻略キャラクター

| キャラ | タイプ | 抱える秘密 |
|--------|--------|------------|
| **結城 陽（ゆうき はる）** | 幼なじみの太陽。元気いっぱいのスポーツマン | 主人公さきと交わした幼い日の「約束」。明るさの裏の、置いていかれる怖さ |
| **氷室 怜（ひむろ れい）** | 孤高の生徒会長。クールで完璧主義のツンデレ | 家に縛られた進路と、誰にも言えない「物語を書きたい」という夢 |
| **七瀬 ひなた（ななせ ひなた）** | やわらかな光。マイペースな美術部の癒し系男子 | 病弱だった過去。完成させられない一枚の絵に込めた「終わりへの怖さ」 |
| **月城 シオン（つきしろ シオン）** | 高嶺の花の先輩。学園中の女子が憧れる美貌のピアニスト三年生 | かつて天才ピアニストだった過去。姉との「最後の約束」を守れず、人前で弾けなくなった |

### エンディング ―― 全100通り

好感度で **結ばれる相手（ルート）** が決まり、道中で集めた選択の組み合わせ（出会い方・デート・支え方・前夜の心持ち…）で **結末が細かく分岐**します。

- **合計100種類のエンディング**（4ルート × 24パターン ＋ 各ルートの破局 ＝ 100）
- エンディングごとに固有の **No.（1〜100）とタイトル** が付き、本文も選択に応じて合成されます
- **エンディング回収率（N / 100）** をブラウザに記録するコンプリート要素つき

> 仕組み：`js/endings.js` が、集めたフラグ（b1〜b4）からタイトルと本文を合成。1〜100すべて到達可能であることを検証済みです。

## 🛠 技術メモ

| 項目 | 内容 |
|------|------|
| 構成 | 素のHTML / CSS / JavaScript（ビルド不要・フレームワーク不使用） |
| 立ち絵 | AI生成イラスト（`images/`）を使用、無ければSVG自動生成にフォールバック。アイドルアニメ（呼吸・ゆらぎ）付き |
| シナリオ | `js/story.js` のシーングラフ（170以上のシーン）＋ `js/endings.js` の100通りエンディング合成 |
| エンジン | `js/engine.js`（進行・好感度・分岐・セーブ・タイプライター演出・音） |
| 音 | Web Audio APIによる手続き的BGM＆効果音（ファイルなし） |
| 演出 | CSSによる桜エフェクト・背景グラデーション・各種アニメーション |
| 対応 | PC／スマホ／タブレットのレスポンシブ対応（縦横画面・ノッチのセーフエリア・`100dvh`・タップ最適化） |
| 保存 | localStorage |

### ファイル構成

```
saki/
├── index.html          # エントリーポイント
├── css/
│   └── style.css       # 全スタイル・背景・アニメーション
├── js/
│   ├── characters.js   # キャラ定義 ＋ SVG立ち絵ジェネレータ
│   ├── story.js        # シナリオ（シーンデータ）
│   └── engine.js       # ゲーム進行エンジン
└── README.md
```

### シナリオの追加・編集

`js/story.js` の `STORY` オブジェクトにシーンを足すだけで拡張できます。

```js
sample: {
  bg: "classroom",                 // 背景キー（css の .bg-xxx）
  who: "saki",                     // 話者: "" 地の文 / "player" 主人公 / キャラID
  exp: "smile",                    // 表情
  text: ["セリフ1ページ目", "2ページ目"],
  eff: { saki: 2 },                // 入室時に好感度加算（任意）
  flag: { met_saki: true },        // フラグ（任意）
  choices: [                       // 選択肢（任意。無ければ next へ）
    { label: "選択肢A", eff: { saki: 2 }, next: "sceneA" },
    { label: "選択肢B", next: "sceneB" },
  ],
  next: "nextSceneId",             // choices が無いとき
}
```
